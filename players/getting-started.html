Getting Started at the Table

Use this portal as a quick reference during play without stepping into spoilers.

How to Use the Wiki

  1. Start with the World Overview to orient on Saint Lore and Thel’aranor Gate.
  2. Check Chapters for summaries when you need a recap.
  3. Use the Transit Hub to select a Western Line destination.
  4. Keep the Tools page open for time, calendar, and reference aids.

Soft Spoilers Explained

Player-facing pages describe tone, stakes, and travel details without revealing outcomes. If a detail feels like a reveal, it should live in the DM area instead.

Transit Selection Basics

Destinations are modular arcs. Pick a destination, then the campaign pivots to that location until the arc concludes.

  • Duration tiers show the expected session count (1 / 2–3 / 4–6).
  • Status tags signal what the city currently knows (Unsurveyed / Active / Restricted).

Soft Lock-In Rule

The party is only committed after exiting transit at a destination. While in the Transit Room, you can discuss, compare, and switch routes.
