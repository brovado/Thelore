Transit Hub

The Transit Room is a sealed chamber lined with old routes and newer notes. While you stand within it, time pauses long enough to read, discuss, and decide.

How the Transit Network Works

Each destination is summarized with a safe briefing. These summaries are designed to let you choose without revealing outcomes or surprises.

Duration Tiers

Tier I One-session outings that resolve quickly.

Tier II Two-to-three session arcs that need a short run of focus.

Tier III Four-to-six session mini-campaigns that change later routes.

Lock-In Rule

While you remain in the Transit Room, you are still able to discuss, change your mind, and select another route. Commitment begins only after you exit the transit.

Once you cross the threshold, return timing depends on the destination you chose.

Return Conditions

Each destination lists when and how return becomes possible. Some are one-and-done, some shift when revisited, and others persist with ongoing changes.

If you are unsure, read multiple briefings before deciding. The Transit Room is the last safe place to compare options.
